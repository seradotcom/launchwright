# SDK and Platform gaps

This document prevents local implementation from being presented as canonical Semwright acceptance.

## Still external to Launchwright

- Canonical Driver Host admission/isolation for the Launchwright NativeDriver
- Canonical Project Graph completeness and effect admission
- Real browser/mobile/Godot source capture through supported drivers
- Composition/AV rendering and media provenance
- Shared team identity, ACLs and remote approval authority
- Production Platform connection and its authoritative cost ledger
- Canonical Publish template/product/version deployment
- Public or cross-account channel delivery
- Store approval, email receipt, social publication and third-party withdrawal observation
- ChatGPT Plugin host acceptance

## Platform Client

The reviewed Platform Client snapshot is `0.3.5-dev.1`, but its source is marked UNLICENSED and is not redistributed. Launchwright loads only an operator-supplied package whose complete runtime source tree matches an owner-provided SHA-256 lock.

Publication actions currently fail closed before network send. Cost-bearing recipe operations require the owner configuration to assert Platform-side budget enforcement.

## Local claims that are safe to make

Launchwright can persist and review release-domain records, render bounded editorial text formats, freeze immutable candidates, export deterministic private ZIP bundles, maintain private aliases with compare-and-swap, journal per-channel attempts with durable pre-send custody and no automatic resend, record bounded withdrawal plans, and export/restore verified local workspace state. It does not yet contain a production external channel adapter, so a ChannelAttempt record is not itself proof that bytes were sent or published.

Those capabilities do not imply external delivery or technical product verification.
